Data manifest¶

Inventory and rights assessment updated 2026-10-01. Public outputs are factual aggregate summaries of utility-reported Massachusetts CSO report rows, with source attribution. They are not independently verified physical discharges.

The AMEND dataset page describes a freely distributed public-source database (checked 2026-10-01). No separate dataset-specific licence was found in the reviewed page. A second check on 2026-10-11 found none either: the AMEND data page and its about page state no licence, and the project's source repository (nesanders/MAenvironmentaldata) declares none (GitHub repository licence field empty and no licence file, read 2026-10-11 00:35 PT). We therefore treat the AMEND files as unlicensed copies of Massachusetts public records: this repository ships no AMEND file, only the derived aggregates listed below, with attribution. The MassDEP policies provide a public-record reuse basis with copyright exceptions; direct access on 2026-10-01 returned 403, so no new blanket permission verification is asserted. The exact shipped fields are computed counts by class/year/identifier, summed volumes, aggregate flag-type counts, bootstrap intervals, support counts and evaluation statistics. Our basis for these outputs is factual aggregation of public records, not a grant to relicense the upstream database. No upstream prose, map tiles or analysis implementation is copied. Attribution is retained in every JSON/HTML/PNG output and in documentation; design licences apply to our original expression only.

Snapshot recovery¶

The live AMEND route refreshes; a hash pin detects changes but cannot ensure perpetual availability. Preserve a lawful private copy of the exact snapshot with this digest. If live acquisition no longer matches, obtain that snapshot from the data owner or an independently permitted archive, place it at data/raw/ma_eea_cso.csv and run cso-insight run --root . --skip-download. The pipeline verifies the same hash before analysis. Never reseal a changed feed as this result. If no matching copy is available, this analysis cannot be regenerated; report that acquisition limitation. The release contains no raw snapshot and makes no immutable-download guarantee.

Preservation during acquisition¶

./scripts/download_data.sh [destination] writes a temporary sibling, verifies the pinned hash, then atomically swaps into a separate acquisition path. Its default is data/raw/ma_eea_cso.download.csv. It refuses the frozen data/raw/ma_eea_cso.csv, including aliases and hard links. Network/hash failures preserve existing files. The Python pipeline also verifies a temporary download before replacement; the helper never overwrites the frozen snapshot.

If the frozen path is absent, a permitted matching acquisition can be installed with test ! -e data/raw/ma_eea_cso.csv && cp -n data/raw/ma_eea_cso.download.csv data/raw/ma_eea_cso.csv. Then run cso-insight run --root . --skip-download, which verifies the hash again. A changed feed requires a separately versioned analysis. Never change this pin to make reproduction pass; recover a matching permitted snapshot or stop.
